# Third-party code and data

The skill-update implementation includes code adapted from [SkillOpt](https://arxiv.org/abs/2605.23904) by Yifan Yang and colleagues. Its [MIT license](third_party_licenses/SkillOpt-LICENSE) is included in this repository.

The stepwise correction module includes verification and revision code and a Python interpreter adapted from [ProgCo](https://github.com/songxiaoshuai/progco) by Xiaoshuai Song and colleagues. Its [license](third_party_licenses/ProgCo-LICENSE) is included in this repository.

The Flash configuration uses DeepSeek tokenizer resources to count tokens for context compression. Their [source](0-4_API/2_model_capacity/tokenizers/deepseek_v41/SOURCE.md) and [license](0-4_API/2_model_capacity/tokenizers/deepseek_v41/LICENSE) accompany the tokenizer.

The [dataset documentation](0-0_datasets/README.md) lists the sources, licenses, and local preparation instructions for the benchmarks. Third-party code, model resources, and data retain their respective licenses.
