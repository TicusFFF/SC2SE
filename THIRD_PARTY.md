# Third-party code and data

The skill-update implementation includes code adapted from [SkillOpt](https://arxiv.org/abs/2605.23904) by Yifan Yang and colleagues. Its MIT license is included in `third_party_licenses/SkillOpt-LICENSE`.

The stepwise correction module includes verification and revision code and a Python interpreter adapted from [ProgCo](https://github.com/songxiaoshuai/progco) by Xiaoshuai Song and colleagues. Its license is included in `third_party_licenses/ProgCo-LICENSE`.

The Flash configuration uses DeepSeek tokenizer resources to count tokens for context compression. `0-4_API/2_model_capacity/tokenizers/deepseek_v41/` contains the source details (`SOURCE.md`) and license (`LICENSE`).

`0-0_datasets/README.md` lists the sources and terms for preparing the paper benchmarks locally.
